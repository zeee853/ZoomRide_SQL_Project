# ZoomRide_SQL_Project
About the Project
This project is a SQL analysis of ZoomRide trip data using MySQL. I used SQL to explore trips, revenue, cities, months, and vehicle types.
I also checked the data for issues such as duplicate records, inconsistent city names, and missing fares, and cleaned the data before carrying out the analysis.

What I Worked On
Explored the ZoomRide trip data
Checked and cleaned inconsistent city names
Identified duplicate records
Checked for missing fares
Analyzed revenue by city
Analyzed monthly revenue
Compared revenue by vehicle type
Used SQL queries to generate insights from the data

Tools Used
MySQL
OneCompiler
ChatGPT(for learning, guidance and troubleshooting)
GitHub

Key Insight
The analysis showed differences in revenue across cities, months, and vehicle types. I also found some data-quality issues that needed to be corrected before making conclusions from the data.
