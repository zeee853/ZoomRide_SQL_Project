ZoomRide SQL Project
About the Project
This is my Week 2 SQL project with Project Builders. I used SQL to analyse ZoomRide trip data, check for data problems, clean the data, and find useful business insights.

Questions and Answers
Q1. How many trips are in the dataset?
The dataset contains 300 trips before cleaning.

Q2. What are the five longest completed trips?
The five longest completed trips came from Lagos (3 trips), Kampala (1 trip), and Abuja (1 trip).

Q3. How many trips are there in each city?
I checked the number of trips recorded for each city and found some inconsistent city names that needed cleaning.

Q4. What data problems did I find?
I found two pairs of duplicate trip records.
